# Portfolio — Ekwe Owona Sone Sone

Portfolio personnel d'un **étudiant en IA & Big Data, développeur web et créateur de solutions d'automatisation**, basé à Douala (Cameroun).

## Aperçu

Site dynamique et responsive, avec un écran d'accueil animé et un portail futuriste à cliquer pour entrer. Il présente mon profil, mes compétences, mes projets et mon CV.

## Rubriques

- **Accueil** : nom, profession et portail d'entrée
- **Présentation** : parcours et objectifs
- **Compétences** : barres de niveau (HTML, CSS, JavaScript, Python, C, Java, PHP, Bootstrap, React, Laravel, Pack Office, Canva)
- **Projets** : réalisations scolaires et personnelles
- **CV** : aperçu et bouton de téléchargement du CV en PDF
- **Contact** : e-mail et téléphone

## Projets présentés

- **SantéConnect** : site de cabinet médical (accès patient avec chatbot, accès administrateur, accès corps médical avec agenda). Équipe de 6, rôle de concepteur front-end. HTML, CSS, React, JavaScript, Bootstrap.
- **GEDA** : gestion électronique des documents administratifs d'un organisme (stockage par département, classement, confidentialité, authenticité, chatbot). Rôle de concepteur front-end. HTML, Tailwind CSS, Blade, JavaScript.
- **Flyer de baptême** : création graphique sous Canva, réalisée seul.

## Technologies

HTML5, CSS3, JavaScript natif, animations au défilement et aux interactions.

## Lancer en local

Ouvre `index.html` dans un navigateur, ou lance un petit serveur :

```
python3 -m http.server 8000
```

puis rends-toi sur `http://localhost:8000`.

## Déployer

- **Vercel** : importe le dépôt, aucun réglage de build (site statique).
- **GitHub Pages** : Settings → Pages → branche `main`, dossier `/ (root)`.

## Structure

À adapter selon le contenu réel de ton dossier :

```
portfolio/
├── index.html
├── css/
├── js/
├── img/            photo et captures d'écran des projets
├── cv/             CV au format PDF
└── README.md
```
